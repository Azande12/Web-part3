# Stellenbosch Pet Grooming - Part 3

Live: https://azande12.github.io/Web-part2/StellenboschPetGrooming/

## What changed from Part 2 to Part 3
Part 2 had only HTML + CSS.
Part 3 added:
- js/main.js: dynamic services, search, lightbox gallery, FAQ accordion, booking modal, Leaflet map (8 Bird St, Stellenbosch), form validation with cost & availability message, active nav
- SEO: title tags, meta descriptions on all 5 pages, alt text with keywords, srcset, robots.txt, sitemap.xml
- CSS animations: fade-in, gallery hover
